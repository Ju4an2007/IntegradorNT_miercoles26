## 📊 Descripción

**ParkingSystem** es una solución integral para la gestión, administración y control de parqueaderos, que integra:

- 🧠 Análisis de datos con Python  
- ⚛️ Frontend en React  
- ☕ Backend con Spring Boot  

Este repositorio corresponde al módulo de **análisis de datos**, donde se procesan, transforman y analizan los datos generados por el sistema para obtener insights como:

- 📈 Ocupación del parqueadero  
- ⏱️ Tiempos promedio de permanencia  
- 💰 Ingresos generados  
- 🚘 Flujo de vehículos  

Se utiliza la librería **pandas** como herramienta principal para el procesamiento de datos.

---

## 🧰 Tecnologías utilizadas

- 🐍 Python 3.10+
- 🐼 pandas
- 📊 NumPy (opcional)
- 📁 CSV / JSON para manejo de datos
